
These are the files supporting the walkthroughs in the NICAR 2025 session [Tidycensus will convince you to learn R](https://nicar.r-journalism.com/2025/)

To open these files in RStudio, run the following commands in your console:

```
install.packages(c("tidycensus", "tidyverse", "mapview", "usethis"))

usethis::use_course("https://github.com/r-journalism/nicar-2025-tidycensus/archive/master.zip")
```
